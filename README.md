# Palash Gupta — Portfolio

Static site (HTML, CSS, JS). No build step.

## Deploy on GitHub Pages
1. Create a new repo (e.g. `palash-portfolio`) and upload ALL files in this folder (keep the `assets` folder).
2. Repo → Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)` → Save.
3. Your site goes live at `https://<your-username>.github.io/<repo-name>/` in about a minute.
   (Name the repo `<your-username>.github.io` to get the shorter URL.)
